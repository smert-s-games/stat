# Быстрый старт

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Первый запуск

1. Запустите программу:
```bash
python main.py
```

2. При первом запуске будет создан файл `config.json` с настройками по умолчанию.

## Настройка

### Статистика по заливам
- Создайте файл `links.txt` со ссылками на YouTube каналы (по одной ссылке на строку)
- Или используйте кнопку "📁 Выбрать файл со ссылками" в программе

### Аккаунты
- Создайте папку `accounts` и поместите туда папки с аккаунтами
- Или используйте кнопку "📁 Выбрать папку с аккаунтами" в программе

### Telegram бот
1. Создайте бота через @BotFather в Telegram
2. Получите Bot Token
3. Получите Chat ID (можно использовать @userinfobot)
4. Введите данные во вкладке "📱 Telegram бот"

## Важные замечания

- Для работы парсинга статистики необходим ChromeDriver
- Для создания видео необходим FFmpeg
- Убедитесь, что ChromeDriver и FFmpeg доступны в PATH
