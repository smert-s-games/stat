# Особенности дизайна

## Современный интерфейс

### Закругленные карточки
- Все секции оформлены как карточки с визуальным эффектом закругления
- Эффект достигается через многослойные фреймы с отступами
- Карточки имеют цветные заголовки

### Темная тема
- Полная поддержка темной темы для всех элементов
- Темный фон (#1a1a1a)
- Темные карточки (#2d2d2d)
- Правильные контрасты для удобочитаемости
- Все виджеты автоматически меняют цвета

### Панель инструментов
- Современная горизонтальная панель вместо меню
- Цветные кнопки с эмодзи
- Эффекты при наведении
- Группировка функций

## Цветовая схема

### Светлая тема
- Фон: #f8f9fa
- Карточки: #ffffff
- Акцент: #0d6efd (синий)

### Темная тема
- Фон: #1a1a1a
- Карточки: #2d2d2d
- Акцент: #0d6efd (синий)
- Границы: #404040

## Типографика
- Основной шрифт: Segoe UI
- Размеры: 9-14pt
- Жирное начертание для заголовков
