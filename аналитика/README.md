# YouTube Analytics - Программа для аналитики

Полноценная программа с удобным графическим интерфейсом для анализа статистики YouTube каналов, управления аккаунтами, создания видео и работы с Telegram ботом.

## Возможности

### 📊 Статистика по заливам
- Парсинг статистики YouTube каналов (просмотры, подписчики, видео)
- Отображение общей и детальной статистики
- История статистики с сохранением данных в базу
- Поиск и фильтрация каналов
- Экспорт результатов в CSV, Excel, JSON
- Графики и визуализация данных

### 👤 Управление аккаунтами
- Добавление нескольких папок с профилями аккаунтов
- Сканирование всех добавленных папок
- Подсчет количества материалов
- Оценка качества аккаунтов
- Удаление аккаунтов (одиночное и массовое)
- Управление списком папок (добавление/удаление)
- Теги для аккаунтов
- Массовые операции (удаление, экспорт, добавление тегов)
- Экспорт аккаунтов в CSV

### 🎬 Создание видео
- Генерация всех возможных перестановок видео
- Склейка видео с помощью FFmpeg
- Настройка количества видео в группе
- Отслеживание прогресса
- Остановка процесса создания

### 🌐 Прокси и сервер
- Управление информацией о прокси
- Управление информацией о сервере
- Отслеживание сроков действия
- Автоматические напоминания об истечении срока (за 7 дней)
- История покупок прокси/серверов

### 📱 Telegram бот
- Интеграция с Telegram ботом
- Отправка статистики
- Уведомления
- Тестовые сообщения

### 🗄️ База данных и история
- SQLite база данных для хранения данных
- История всех операций
- История статистики каналов
- Логирование всех действий

### 📅 Планировщик задач
- Автоматический парсинг статистики по расписанию
- Настройка времени выполнения задач
- Ежедневные, еженедельные задачи

### 🎨 Интерфейс
- Светлая и темная темы оформления
- Современный интерфейс
- Удобная навигация

### 📄 Отчеты и экспорт
- Генерация текстовых отчетов
- Экспорт статистики в CSV, Excel, JSON
- Экспорт аккаунтов в CSV
- Детальные отчеты с анализом данных

## Установка

1. Установите Python 3.8 или выше
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Установите ChromeDriver для Selenium:
   - Скачайте ChromeDriver с https://chromedriver.chromium.org/
   - Убедитесь, что он доступен в PATH

4. Установите FFmpeg (для создания видео):
   - Скачайте FFmpeg с https://ffmpeg.org/download.html
   - Убедитесь, что он доступен в PATH

## Запуск

```bash
python main.py
```

## Использование

### Статистика по заливам
1. Перейдите на вкладку "📊 Статистика по заливам"
2. Нажмите "📁 Выбрать файл со ссылками" и выберите файл с ссылками на каналы
3. Нажмите "🔄 Обновить статистику"
4. Дождитесь завершения парсинга
5. Используйте поиск для фильтрации каналов
6. Нажмите "📊 История" для просмотра истории статистики
7. Нажмите "💾 Экспорт" для экспорта данных в различных форматах

### Управление аккаунтами
1. Перейдите на вкладку "👤 Аккаунты"
2. Нажмите "➕ Добавить папку" для добавления папки с профилями аккаунтов
3. Можно добавить несколько папок - все аккаунты из всех папок будут отображаться вместе
4. Программа автоматически просканирует все добавленные папки и отобразит статистику
5. Для удаления папки из списка выберите её в списке папок и нажмите "➖ Удалить выбранную папку"
6. Для удаления аккаунта выберите его в таблице и нажмите "🗑️ Удалить аккаунт"
7. Используйте "📋 Массовые операции" для массового удаления, экспорта или добавления тегов
8. Используйте "🏷️ Теги" для управления тегами аккаунтов

### Создание видео
1. Перейдите на вкладку "🎬 Создание видео"
2. Укажите папку с исходными видео
3. Укажите папку для готовых видео
4. Установите количество видео в группе
5. Нажмите "▶️ Запустить создание видео"

### Прокси и сервер
1. Перейдите на вкладку "🌐 Прокси и сервер"
2. Введите даты покупки и окончания для прокси и сервера
3. Нажмите "💾 Сохранить"
4. Программа автоматически будет напоминать об истечении срока за 7 дней

### Telegram бот
1. Перейдите на вкладку "📱 Telegram бот"
2. Введите Bot Token и Chat ID
3. Нажмите "💾 Сохранить настройки"
4. Нажмите "▶️ Запустить бота"

## Конфигурация

Настройки сохраняются в файле `config.json` в корне проекта.

## Структура проекта

```
.
├── main.py                 # Главный файл приложения
├── stats_tg.py            # Оригинальный скрипт парсинга
├── start.py               # Оригинальный скрипт создания видео
├── modules/               # Модули приложения
│   ├── __init__.py
│   ├── stats_parser.py    # Парсинг статистики
│   ├── account_manager.py # Управление аккаунтами
│   ├── video_creator.py   # Создание видео
│   ├── proxy_manager.py   # Управление прокси
│   ├── telegram_bot.py    # Telegram бот
│   ├── database.py        # База данных SQLite
│   ├── stats_history.py   # История статистики
│   ├── export_manager.py  # Экспорт данных
│   ├── scheduler.py       # Планировщик задач
│   ├── theme_manager.py   # Управление темами
│   └── report_generator.py # Генератор отчетов
├── config.json            # Файл конфигурации
├── analytics.db           # База данных SQLite (создается автоматически)
└── requirements.txt       # Зависимости
```
